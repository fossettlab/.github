# Fossett Laboratory

Geospatial field methods, AI-driven analysis, and extended-reality
applications at Washington University in St. Louis.

<https://fossettlab.org>

## GeoXplorer family

HoloLens / mobile AR / desktop geoscience exploration apps.

- [xr-geoxplorer](https://github.com/fossettlab/xr-geoxplorer) — unified HoloLens + iOS/Android explorer (current head, Unity 2019.4, MRTK2 + Photon + Azure Spatial Anchors)
- [xr-geoxplorer-mobile](https://github.com/fossettlab/xr-geoxplorer-mobile) — mobile-only branch (AR Foundation). Was published to the App Store / Play Store as `com.FossettLab.GeoXplorer`
- [xr-geoxplorer-se](https://github.com/fossettlab/xr-geoxplorer-se) — shared-experience HoloLens variant (multi-user)
- [xr-geoxplorer-v1](https://github.com/fossettlab/xr-geoxplorer-v1) — 2018 HoloLens-1 baseline, original git history preserved
- [xr-geoexplorer-original](https://github.com/fossettlab/xr-geoexplorer-original) — 2017 predecessor (reference only)

## Standalone teaching & research applications

- [xr-crystalviewer](https://github.com/fossettlab/xr-crystalviewer) — crystal-structure viewer (HoloLens)
- [xr-lro-asset-bundles](https://github.com/fossettlab/xr-lro-asset-bundles) — Lunar Reconnaissance Orbiter viewer (Apollo landing sites)
- [xr-rover-traverse](https://github.com/fossettlab/xr-rover-traverse) — rover path visualization
- [xr-volcano-viewer](https://github.com/fossettlab/xr-volcano-viewer) — volcano visualization
- [xr-seismicity-viewer](https://github.com/fossettlab/xr-seismicity-viewer) — seismicity / earthquake viewer
- [xr-kilauea-sono](https://github.com/fossettlab/xr-kilauea-sono) — Kilauea DEM sonification (desktop)
- [xr-3d-phase-diagrams](https://github.com/fossettlab/xr-3d-phase-diagrams) — petrology phase-diagram interactive (desktop)
- [xr-virtual-earth-2](https://github.com/fossettlab/xr-virtual-earth-2) — HoloLens geospatial viewer
- [xr-intermediate-triggering](https://github.com/fossettlab/xr-intermediate-triggering) — MRTK + Photon networked HoloLens app
- [xr-museum-viewer](https://github.com/fossettlab/xr-museum-viewer) — 3D museum-artifact viewer (Buddhist sculptures, Met Museum objects)
- [xr-dco-demo](https://github.com/fossettlab/xr-dco-demo) — Deep Carbon Observatory demo (HoloLens + WebGL)
- [xr-meltcomplex](https://github.com/fossettlab/xr-meltcomplex) — magma phase-diagram teaching (HoloLens 1 legacy)

## Status

Most XR projects above are archived (last active development 2017–2021).
Revival of any would require Unity LTS upgrade (2019.x → 2022.3 LTS or
Unity 6) and likely a MRTK 2 → MRTK 3 / OpenXR migration.
